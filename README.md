A GTA 6 meme for make.fun's "Post a GTA 6 meme on X" bounty: 2013 vs 2026 — one gamer waits thirteen years for GTA 6 and grows a grey beard doing it, while the make.fun ghost beside him shows his AI agent already got paid. The meme went up on X from a public account, and `POST.json` at this repository's root names the post's address; `main.ts` copies it to `/output/POST.json` for the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
